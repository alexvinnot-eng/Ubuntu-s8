# v0.2.4 run-init console bypass

The SM-G955F v0.2.3 hardware log proved that Samsung S-Boot overwrites the
embedded DTB bootargs with an ATAG command line containing `console=ram`.
Consequently, the length-neutral DTB patch from v0.2.3 cannot affect the final
kernel command line.

Userdata, `ubuntu.img` and the embedded Android API 30 image still mount
successfully. The actual handoff blocker remains:

```text
run-init: opening console: No such device
Target filesystem doesn't have requested /sbin/init.
```

v0.2.4 patches the Halium initramfs `/init` instead of the DTBs. Both the dry
run validation and final handoff invoke klibc `run-init` with
`-c /dev/null`, avoiding the nonexistent `/dev/console`. The final shell-level
redirections to `/dev/console` are removed. The kernel, DT image and Ubuntu
rootfs are unchanged.

The installer writes only BOOT and requires the existing
`/data/ubuntu.img` from v0.2.2.
