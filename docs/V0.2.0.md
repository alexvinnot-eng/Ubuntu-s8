# v0.2.0 full-rootfs bring-up image

This build is for the Samsung Galaxy S8+ Exynos SM-G955F only. It is an early
hardware bring-up build, not a daily-use Ubuntu Touch release.

The TWRP installer contains:

- the hardware-tested LineageOS 18.1 kernel and DT from the 2025-06-28
  `dream2lte` build;
- the patched Halium diagnostic initramfs used by v0.1.4;
- the Ubuntu Touch 20.04 arm64 rootfs;
- the Halium 11 arm64 Android container;
- an ext4 vendor image extracted from the pinned LineageOS package;
- minimal `dream2lte` configuration for HWC2, gbinder API 30 and Samsung USB.

The installer writes the root filesystem to `/data/ubuntu.img` through a
temporary file, verifies its SHA-256, then atomically renames it. BOOT is only
written after rootfs verification succeeds. It does not format userdata,
SYSTEM or EFS.

Validated hashes:

- `boot.img`: `7808c46e992c4bc605b259033d2a54ea51e74f32538fc520c9e7aa4d83833cc9`
- `ubuntu.img`: `b343f33cf9423fa2eaba5742546a1b7c6dea77d57def1090378b7ea0a54f651c`
- full TWRP ZIP: `39ca28aa755377226062f71bb6b61fa01e8a79a5995ef47a50952515b805979e`

The archive and both ext4 files pass integrity checks. Hardware behavior after
the Linux-to-Lomiri handoff is not yet validated and must be diagnosed from
the first device boot.
